В ходе выполнения работы решаются следующие задачи:

Получение данных с ЦБ РФ - запрос к API http://www.cbr.ru/scripts/XML_daily.asp, который возвращает XML-документ с курсами валют на текущую дату.

Парсинг XML - извлечение названия валюты, её буквенного кода (CharCode), значения курса и номинала.

Объектно-ориентированная обёртка - создание класса CurrenciesLst, инкапсулирующего логику работы с валютами.

Шаблон «Одиночка» - гарантия того, что в программе может существовать только один экземпляр класса CurrenciesLst.

Контроль частоты запросов - защита от слишком частых обращений к серверу ЦБ (по умолчанию не чаще одного раза в секунду).

Хранение чисел с плавающей точкой - значение курса хранится отдельно в виде целой и дробной частей (кортеж строк), что соответствует рекомендациям из документации Python о представлении чисел с плавающей точкой.

Учёт номинала - если номинал валюты не равен 1 (например, 10 или 100 единиц), это сохраняется, чтобы избежать путаницы при переводе в рубли.

Визуализация - построение столбчатой диаграммы курсов валют и сохранение её в файл currencies.jpg для отчёта.

Тестирование - проверка корректной работы на правильных и неправильных идентификаторах валют.
